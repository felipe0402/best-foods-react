# Best Foods

Interface responsiva de um serviço de alimentação, construída em React para explorar composição de componentes, filtros e apresentação de cardápio.

**Demo:** [best-foods-react.vercel.app](https://best-foods-react.vercel.app/)

## Funcionalidades

- Navegação responsiva com menu lateral em telas menores;
- destaque de ofertas e categorias;
- cards de produtos;
- filtro de alimentos por categoria;
- filtro por faixa de preço;
- seções de serviços e conteúdo multimídia;
- metadados da página gerenciados com React Helmet.

## Tecnologias

- React 18
- JavaScript
- Tailwind CSS 3
- React Icons
- React Player
- Create React App

## Como executar

Requisitos: Node.js e npm.

```bash
git clone https://github.com/felipeand-dev/best-foods-react.git
cd best-foods-react
npm install
npm start
```

A aplicação será aberta em `http://localhost:3000`.

## Scripts

```bash
npm start       # desenvolvimento
npm test        # testes em modo interativo
npm run build   # build de produção
```

## Escopo

O projeto demonstra a experiência de navegação e filtragem do cardápio. Não há checkout, autenticação, pagamento ou persistência de pedidos.

## Objetivo

Praticar estado em React, renderização de listas, filtros derivados, responsividade e organização de uma interface em componentes.
